Лабораторна робота №3 — CRC-32 (варіант 17)
==========================================

Потрібні Python 3.10+ та matplotlib для автоматичної побудови PNG.
Всі команди виконуються з папки, де лежать benchmark.py та crc32_lab.py.

1. Установити залежність (лише один раз):
   python -m pip install matplotlib

2. Перевірити алгоритми:
   python crc32_lab.py

3. Запустити тести (очікується 8 тестів, OK):
   python -m unittest -v test_crc32.py

4. Запустити експеримент і АВТОМАТИЧНО створити графік:
   python benchmark.py --messages 1000 --repeats 10 --seed 17 --output results_final

Після команди №4 з’являться файли:
   results_final/benchmark_results.csv
   results_final/benchmark_results.json
   results_final/crc_timing.png

Графік відповідає саме середньому часу та стандартним відхиленням із JSON
цього запуску. При повторному запуску з таким самим --output усі три
файли перезаписуються, щоб не було застарілого графіка.

Щоб перемалювати графік БЕЗ повторного бенчмарку:
   python plot_results.py --input results_final

Для іншої папки результатів, наприклад results_verify:
   python plot_results.py --input results_verify

Вимірюється час обчислення для 1000-бітових повідомлень; створення
даних і таблиць до часу НЕ входить. Результати з іншого запуску можуть
відрізнятися, навіть якщо програмний код і вхідні дані ті самі.

Графік використовує matplotlib. Якщо пакет не встановлено, скрипт
зберігає CSV/JSON і підказує, як встановити matplotlib.

ВІДПОВІДНІСТЬ МЕТОДИЧЦІ (важливо для захисту):
- Прямі: дописування 32 нулів (для байтової реалізації 4 байти), зсув вліво.
- Дзеркальні: БЕЗ дописування нулів, зсув вправо, відбитий поліном.
- Табличний дзеркальний: i = (reg ^ byte) & 0xff, reg = (reg >> 8) ^ table[i].
- Для збігу контрольних сум вхідні байти відбиваються перед дзеркальним
  табличним алгоритмом, а готовий 32-бітний результат — у прямий порядок.
- Значення 0x169A5FA5 для seed=17 збережено.
- Після зміни алгоритмів старі вимірювання часу НЕ можна вважати
  вимірюваннями нового коду. Перезапусти benchmark.py і онови звіт.
